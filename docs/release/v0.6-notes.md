# Flow-Factory v0.6.0

Flow-Factory v0.6.0 adds three ways to optimize a differentiable reward, plus opt-in FSDP2
placement for SD3.5 ReFL auxiliaries. It also includes DiffusionART, which trains from ordinary
reward scores and retained Euler trajectories.

## Training

| Path | Release scope |
| --- | --- |
| [ReFL](https://github.com/X-GenGroup/Flow-Factory/blob/v0.6.0/guidance/training/refl.md) | Optimize a selected denoising step through its clean prediction. All 19 registered adapters expose differentiable decoding, with model-specific modality and layout limits. |
| [DRaFT-K](https://github.com/X-GenGroup/Flow-Factory/blob/v0.6.0/guidance/training/draft.md) | Score the final SD3.5 image and differentiate the final K contiguous Euler ODE steps. Supports local, data-only DDP, and FSDP2 policy execution with replicated auxiliaries. |
| [DRTune](https://github.com/X-GenGroup/Flow-Factory/blob/v0.6.0/guidance/training/drtune.md) | Differentiate K spaced velocity predictions on SD3.5 Euler ODE. Stop gradients through each denoiser input while carrying the live latent gradient. Score the native endpoint or an early clean projection. Supports local, data-only DDP, and FSDP2 policy execution with replicated auxiliaries. |
| [DiffusionART](https://github.com/X-GenGroup/Flow-Factory/blob/v0.6.0/guidance/training/art.md) | Train from complete prompt groups using shared trajectory retention and configurable sequential updates. |

Differentiable rewards declare their supported input fields. Frozen decoders and scorers
preserve input gradients back to the trainable policy. PickScore provides the built-in
differentiable image and video scorer. Observation-only rewards remain available for evaluation.
For single-source SD3.5 ReFL, use the
[sharded recipe](https://github.com/X-GenGroup/Flow-Factory/blob/v0.6.0/examples/refl/lora/sd3_5/pickscore_fsdp2.yaml)
to opt in to FSDP2 for the text encoders, frozen VAE and synchronous PickScore. The default
auxiliary placement is replicated. Training sample media uses the shared logging path and
`max_logged_train_samples`.

## Upgrade and installation

Use Python 3.11 or newer and PyTorch 2.11 or newer. Torch 2.11 fixes the earlier autocast
weight-cache behavior that could drop parameter gradients after a no-grad denoising step.
The CUDA image uses Python 3.12, Torch 2.11.0 with CUDA 12.9, Diffusers 0.42.1 and Accelerate
1.15.0. It ships TorchAudio 2.11.1 and TorchCodec 0.12.0 CPU wheels with FFmpeg shared libraries.
See the [installation guide](https://github.com/X-GenGroup/Flow-Factory/blob/v0.6.0/guidance/installation.md)
for source installs and
[loading and resume](https://github.com/X-GenGroup/Flow-Factory/blob/v0.6.0/guidance/configuration/loading-and-resume.md)
for training-state compatibility.

```bash
docker pull ghcr.io/x-gengroup/flow-factory:0.6.0
```

The Release assets include the wheel, source distribution, `SHA256SUMS`, and the evidence archive
with the tag identity, resolved dependencies, image digest and offline smoke report.

## Qualification

- The [integrated candidate](https://github.com/X-GenGroup/Flow-Factory/actions/runs/45119052640)
  covers ReFL with real PickScore and jointly sharded auxiliaries, DRaFT-K and DRTune on DDP and
  FSDP2, and representative SD3.5 TP/SP/CP and ordered DPPO cases.
- The [final training PR gate](https://github.com/X-GenGroup/Flow-Factory/actions/runs/45130111738)
  requalifies the updated dependency floor and both SD3.5 differentiable samplers on DDP and
  FSDP2. Focused CPU and GPU checks cover Torch 2.11.0, 2.12.1, 2.13.0 and 2.14.1.
- The [CUDA image preview](https://github.com/X-GenGroup/Flow-Factory/actions/runs/45130104166)
  verifies the locked cu129 environment and an offline SD3.5 denoiser update. The Release
  evidence records the separate build from the tagged source.

The [milestone](https://github.com/X-GenGroup/Flow-Factory/blob/v0.6.0/roadmap/milestones/v0.5x-v0.6.md#v06-release-gate)
records the exact tested commits and supported combinations. The
[DRTune timing results](https://github.com/X-GenGroup/Flow-Factory/blob/v0.6.0/guidance/training/drtune.md#sd35-medium-timing)
describe step time and allocation for one matched SD3.5 workload. Expert parallelism is the next
[roadmap milestone](https://github.com/X-GenGroup/Flow-Factory/blob/v0.6.0/roadmap/milestones/v0.6-v0.7.md).
