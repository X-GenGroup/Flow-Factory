## Reproduction commands

Use the installed artifact environment, unset `PYTHONPATH`, set `OMP_NUM_THREADS=1`,
`MKL_NUM_THREADS=1`, `TOKENIZERS_PARALLELISM=false`, and disable network model loading.
Tests construct tiny native local fixtures; no pretrained downloads are required.

```bash
python -m accelerate.commands.launch --config_file config/validation/backends/zero2.yaml --module pytest -q tests/distributed/test_model_preparation.py::test_cuda_backend_prepares_one_root_and_updates_both_routes --backend zero2
python -m pytest -q 'tests/distributed/test_context_parallel_state.py::test_cuda_wan_sft_cp_state_resume[1-lora]'
python -m pytest -q tests/distributed/test_flux_coupled_overlap.py::test_cuda_flux_tp_cp_dppo_ready_lora
python -m pytest -q tests/distributed/test_flux_sequence_context_parallel.py::test_cuda_flux_kontext_sp_guard_ordered_full
```
