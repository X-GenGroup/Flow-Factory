### What the probability means

```yaml
train:
  trainer_type: sft
  condition_dropout: 0.1
```

For each training record, use its ordinary conditioning with probability `1-p` and its
adapter's caption-absent conditioning with probability `p`. The default is zero. Accept
finite probabilities from zero through one. Train one velocity prediction on the selected
branch with the demonstration target and ordinary SFT loss. Reuse the selected branch for
every sampled timestep in that microbatch.

For example, a Klein Base edit of a portrait with the instruction “add glasses” supplies the
same portrait on both branches. On a dropout event the model predicts from the portrait and
empty text. This trains the baseline that its text guidance subtracts during inference.
An arbitrary negative instruction in a dataset describes a third condition. Reuse stored
negative embeddings only when they encode the exact canonical training baseline.

For checkpoints with explicit text CFG, use the native baseline of that guidance axis, including
its template, masks, media, and positions. For guidance-distilled checkpoints, define and test
caption dropout as an opt-in SFT augmentation. Report it as such in the support table.
Multi-axis guidance recipes need an explicit distribution over their branches. This scalar
selects the text axis. It gives every model one documented meaning.

### One decision, two ways to prepare the input

SFT owns a stateless decision keyed by training seed, data epoch and record ID in its own RNG
namespace. It is independent of row order, timestep and target-noise draws, and agrees across
TP/SP/CP peers holding the same record. Include the enabled probability and branch policy version
in the execution identity. Preserve legacy checkpoint identity at zero. Evaluation uses the
ordinary inference inputs. A dropout event selects one forward and carries the same target media,
target geometry and active loss regions as the original record.

The adapter owns how to produce the selected condition. Use the existing offline input projection,
condition preparer and output binding. The branch must reach every model-consumed representation,
including pooled outputs, attention masks, token IDs and packed contexts. Keep original record
IDs, provenance and source conditions intact. [SFT training path](../../src/flow_factory/trainers/offline/sft.py)
· [prepared condition](../../src/flow_factory/models/condition_state.py)

| Data configuration | Planned behavior |
| --- | --- |
| `enable_preprocess: true` | Prepare the ordinary input through the existing cache. When enabled, also make the caption-absent representation available. Share deterministic empty text across records for the same encoder, template, precision and length. For joint vision-language encoders, key the alternate encoding by retained media content, order, preprocessing and workflow identity. Store only the differing representation and reuse shared media latents. Select at batch time. A warm reusable cache defers encoder loading, and `p=0` skips alternate preparation. |
| `enable_preprocess: false` | Validate V2 inputs and decode the input media for the raw batch, keeping supervised targets separate. Select the branch before encoding. On the training rank, use the adapter's existing encoding functions with the original or caption-absent presentation, then prepare and bind the result exactly as for a cached row. Perform frozen encoding once for the selected input. DataLoader workers handle CPU data only. Use the runtime load coordinator for encoding modules. |
