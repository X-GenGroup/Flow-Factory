## P23: selectable SFT conditioning dropout

- **Status:** planned
- **Depends on:** [P14](v0.5.md#p14), the qualified offline-training baseline
- **Coordination:** unclaimed
- **Release boundary:** next available v0.6.x release after P23a and P23b qualify

### Training behavior

For a denoiser trained with classifier-free guidance in mind, supervised flow matching needs
examples in which the selected condition is absent. Draw one mask per logical training record
per data epoch. Apply it to the model input and use the same demonstration target, noising,
timestep, and velocity supervision. Reuse that condition for every timestep term within the
microbatch. This follows the conditional and null training objective in
[Classifier-Free Diffusion Guidance, Algorithm 1](https://arxiv.org/pdf/2207.12598#page=4).

For T2I, dropping text trains the null-text prediction. For I2I, text dropout keeps the
reference images and trains an image-conditioned prediction with null text. Dropping text and
references together trains against the same target with both inputs absent. Each mode supplies
a different conditioning branch. A recipe should choose the branches it plans to use.
Separate probabilities for multiple outcomes can be added when a recipe needs them.
[InstructPix2Pix, §3.2.1](https://arxiv.org/html/2211.09800#S3.SS2.SSS1) illustrates this schedule
with distinct text-only, image-only, and joint drop events.

### Proposed configuration

```yaml
train:
  trainer_type: sft
  condition_dropout:
    probability: 0.10
    fields: [text]
```

Omitting `condition_dropout` or setting `probability: 0` takes the existing SFT path. The example
probability is a recipe choice. At `1` every row drops the requested fields. For FLUX.2 I2I, use
`fields: [text, reference_images]` to drop both together on the same draw. An adapter can also
admit `[reference_images]` for text-only conditioning of the target. Dropping an already absent
optional reference is a no-op for that field. The first release uses one joint Bernoulli draw
for the selected set.

`fields` selects adapter-declared groups of sample input fields. A selection applies atomically
to the whole group. The SFT argument parser validates a finite probability in `[0, 1]` and a
nonempty, duplicate-free selection when enabled. Resolve the adapter class via the registry and
reject unknown selections and unsupported model variants before weight loading. Give the model,
request, and supported selections in the error. The supported-field table grows with adapter
support. Output media, target latents and their position IDs, clocks, labels, and record identity
are outside the selection surface.

| Initial adapter | Selectable condition | Replacement |
| --- | --- | --- |
| SD3.5 T2I | `text` | The adapter's empty-prompt encoding. Replace the positive sequence and pooled embeddings together, plus any positive prompt IDs or model-consumed raw text. |
| FLUX.2 and FLUX.2 Klein | `text` | The adapter's empty-prompt embedding and matching `text_ids` and `prompt_ids`, with the same tokenizer template, output layers and sequence length. |
| FLUX.2 and FLUX.2 Klein I2I | `reference_images` | An empty reference list and absent `image_latents` and `image_latent_ids` for the row. Omit its reference tokens from the transformer input. |

Native empty inputs define the reference for numerical tests. Zero-valued reference tokens can
still alter attention because the tokens remain in the sequence. Keep learned guidance inputs,
such as FLUX.2 Dev's offline forward override, separate from the dropout decision. For an adapter
with required input media or a media condition that sets target geometry or active loss regions,
qualify its own null and target semantics before admitting the group. Cached text encoding in
this milestone assumes a frozen encoder. Training that encoder requires a live encoding graph.

### Current data path and integration

1. The [offline loader](../../src/flow_factory/data_utils/offline_train_data.py) projects inputs
   into an Arrow cache. [`OfflineCollator`](../../src/flow_factory/data_utils/offline_dataset.py#L387)
   collects the condition mapping separately from `target_media`, original model inputs and
   provenance. The finite [acquisition driver](../../src/flow_factory/trainers/execution.py#L180)
   sets the sampler's `data_epoch`.
2. [SFT](../../src/flow_factory/trainers/offline/sft.py#L68) moves the cached conditions to the
   device, prepares input state, encodes the demonstration with its output codec, and binds the
   output context before velocity matching. Insert dropout after collation on an ephemeral input
   mapping before device transfer and `prepare_condition_state()`. Reuse the prepared input and
   output binding across all existing timestep terms. Each admitted condition must preserve the
   target tensor, output geometry and loss mask. Evaluation continues to consume the original
   data and conditions.
3. SFT owns policy validation, row selection and metrics. The adapter declares supported groups
   and performs their null replacement. Reuse the existing condition preparer and
   [output-context binding](../../src/flow_factory/trainers/common/offline_batch.py), with the
   existing model-neutral `OfflineBatch` and V2 manifest. Treat cached containers and tensor
   leaves as read-only.
4. Keep one deterministic null-text bundle per effective frozen encoder/preprocessing identity.
   Prepare or resolve it with the existing deferred preprocessing load and synchronization
   mechanism, using the same native encoder, revision, precision, tokenizer/template, length
   and output-layer settings as the positive path. Cache it separately from the per-record
   condition cache. Probabilities, drop masks and epochs never enter the positive cache key.
   With both caches warm, skip loading the text encoder. With dropout disabled, skip the null
   lookup and any additional module loads. The training loop selects cached fields rather than
   invoking the text encoder each step.
5. Derive the Bernoulli draw with an independent RNG namespace from the training seed,
   `data_epoch`, and the stable `record_id`. Every TP/SP/CP rank holding the same record gets
   the same decision. Different DP replicas may make different decisions for different records.
   A padded repeat of the same record in one sampler epoch gets the same decision. Masks follow
   record identity under row reordering and survive exact fixed-topology continuation without a
   mutable RNG cursor. The existing training RNG streams retain their keys and consumption.
   Include enabled probability, canonical field set and mask/null convention in execution
   identity. Omit the disabled policy from that identity to preserve legacy disabled checkpoints.

The assessed main was `e0eb1382`. [#395](https://github.com/X-GenGroup/Flow-Factory/pull/395)
corrected continuous `time_shift` to scale noise odds as intended and bound the new convention
to affected checkpoint identities. Dropout needs its own RNG and identity. It leaves the
sampling distribution and target noise under the existing SFT owners.

### FLUX.2 packed inputs and distributed schedule

The [FLUX.2 forward](../../src/flow_factory/models/flux/flux2.py#L991) and
[Klein forward](../../src/flow_factory/models/flux/flux2_klein.py#L1022) choose a batched T2I path
when the entire `image_latents` argument is `None`, and a per-sample path when a reference
container is present. Preserve the per-row containers for a reference-capable dropout batch,
including a list of `None` values on an all-dropped rank. The adapter should select a stable
call schedule across the prepared FSDP2 group for the admitted dataset configuration. Do not
derive a rank's forward count from its realized dropout mask. Use the existing per-sample path
for mixed or ragged reference rows. Keep target positions and the live reference ordering for
rows that retain their references.

The [native CP guard](../../src/flow_factory/models/flux/_flux2_parallel.py#L352) requires matching
latent and position-ID layouts plus divisible text and combined image token counts. Check both
kept and dropped shapes, including the target-only span. The admission or preflight must fail
consistently before model collectives if either shape is invalid.

- **Status:** planned

### P23b: FLUX.2 text and reference dropout

- **Status:** planned
- **Depends on:** [P23a](#p23a)
- **Coordination:** unclaimed
- **Scope:** adopt the field policy in FLUX.2 and FLUX.2 Klein, with T2I, I2I, and their optional
  reference inputs. Publish a recipe for text-only dropout and one for the joint selection.
- **Acceptance:** CPU/native parity for both adapters, including multi-reference order,
  empty/mixed/ragged reference rows, paired IDs, keep/drop text and joint replacement.
  Compare target/noise/loss and policy derivatives to explicitly constructed native inputs.
  Run one two-GPU FSDP2 witness with batch size greater than one and deliberately different
  masks on two DP ranks, including an all-dropped and an all-kept rank. Use the smallest
  composed mesh that exercises any advertised TP/SP/CP path, such as DP2 × CP2 for CP or
  DP2 × TP2/SP × CP2 if publishing their joint support. Check gradients, updates and resumed
  mask sequences. Add further model/backend combinations only for distinct contracts.

The implementation touches offline objective inputs, cache lifecycle, and distributed/resume
contracts. Classify each implementation PR against the actual diff and attach selected evidence.
After both PRs qualify, record their supported model/layout pairs and the v0.6.x tag separately
from the published v0.6.0 baseline. Remaining adapters can adopt the same contract after their
null fields and supported geometries are verified.
