Bagel's final ledger entry requires an independent canonical serial arithmetic reference
at each current actual-model state. It rebuilds its own native prefixes and reproduces TP
contractions and CP attention geometry without production parallel helpers. Native generation
RMSNorm calls retain their functions, weights and epsilon while matching physical CP/SP residual
row groups; final root norms use CP groups after SP gather. Independent FP64 operator/VJP
controls and packing, masking, head and CP-factor negatives remain separate requirements.

The output limits are unchanged. Every gradient element retains the shared `atol=1e-3`,
`rtol=0.02` budget, with the `2/128` relative-L2 cap applied once to the complete gradient
dictionary. Per-parameter and memory-window relative statistics are diagnostic; partitioning
the same signal must not change acceptance. The actual model advances without resets, the
reference has no optimizer, and FP64 own-gradient Adam checks cover every actual parameter,
moment and update across three warm steps. The original monolithic Flash, ungrouped-norm,
autonomous-trajectory and regional-cap failures remain failed records. This contract
does not relabel those runs or qualify released weights. The final full/LoRA, SP-off/on and
conditioned lifecycle cases passed at the Bagel source recorded in the ledger; the historical
failures remain separate observations.

The ordinary runtime boundary remains FSDP2, BF16, AdamW, one sample per device,
`dp_replicate=1`, `dp_shard>=2`, and a declared concrete trainer capability. Model guards supply
more specific limits. The principal composed model witness is eight local ranks at DP2×TP2×CP2;
full/LoRA and SP choices are recorded per case, not inferred from that mesh label. No new
cross-node, convergence or performance claim follows. Shared Ring qualification establishes a
transport primitive; none of the model rows above claims a model-level Ring lifecycle.

These Git pins are execution preflight declarations, not presently serialized checkpoint fields.
An incompatible semantic dependency change must bump the capability version; dependency and
artifact compatibility remain P13 acceptance. CP1 identities remain unchanged where stated by
the model identity controls. Earlier ordinary Flux/Qwen CP checkpoints predate their
`tensor_parallel=True` capability and do not satisfy the new strict CP resume identity.

Checkpoint loading compares saved tensors, optimizer/auxiliary state, runtime identity and RNG
exactly. The ordered-overlap contract also requires exact work membership/order and checks the
first resumed update from the same state under the original numerical bounds. Every later
actual update must satisfy its own objective/public-output derivative, clipping/Adam, EMA and
state checks. Later cross-run gradient/update statistics are diagnostic: accepted BF16 drift
can select different nonlinear clipping branches. Independent native model probes separately
own parameter-gradient equivalence; an own-gradient optimizer check is not that proof.
This ordered-overlap contract leaves the separate SFT and online state-runner checks unchanged.
Ready reward completion can vary while sample identity, valid accumulation and state ownership
remain mandatory. Arbitrary in-flight recovery, topology-changing optimizer continuation and
EP/MoE are separate work. Packed TP preserves canonical parameter/PEFT/state ordering through
reversible activation exchanges; the additional communication has no implied speedup.
